Simple wave visualization project for my Physics 1 class.

The goal of this interactive visualization is to show 2 things:
1. visually showing that the classical wave equation correctly describes a sinusoidal wave
2. visualizing the reflection of a simulated wave on a free or fixed end

Key features:
1. variable amplitude, wave length and frequency
2. pausing and reseting the waves

How to run?
You can run this project by downloading the project and running the index.html file in your browser. This simulation requires JavaScript to perform the real-time physics calculations and rendering. Please ensure JavaScript is enabled in your browser settings to view the wave dynamics.

Note:
The simulation can glitch during the first few frames. If that happens, just restart the simulation with the button until the glitch disappears.
